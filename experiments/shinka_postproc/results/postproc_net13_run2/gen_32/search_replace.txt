<DESCRIPTION>
Add a short path-relinking phase from each selected parent toward a distant, high-quality archived network. The path is built from valid degree-preserving two-switches that strictly reduce the symmetric difference from the target. A few of these intermediate networks are reserved for LP evaluation, so the surrogate ranking cannot screen out every guided move. This complements local neighborhood search with directed exploration between promising regions while keeping the added work bounded.
</DESCRIPTION>
