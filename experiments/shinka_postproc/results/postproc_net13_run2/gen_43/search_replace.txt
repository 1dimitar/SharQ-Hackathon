<DESCRIPTION>
Add a small path-relinking neighborhood toward a strong, structurally distant network already scored by the LP. Each intermediate is generated by a degree-preserving two-switch that increases overlap with the target, so the path moves deliberately toward another promising region rather than taking arbitrary kicks. A few best-overlap choices are added as proposals for the existing surrogate screen; the search does not spend LP calls on every path step. This gives stalled and non-stalled parents a bounded way to combine good structures from distinct archive members without substantially increasing neighborhood-generation cost.
</DESCRIPTION>

        # Relink toward a strong, distant archive member. Each step increases
        # shared edges, while the existing screen decides which steps merit LP calls.
        targets = [
            target for target in sorted(seen, key=seen.get)[:12]
            if target != net and distance(net, target) >= 6
        ]
        if targets:
            target = targets[int(rng.integers(len(targets)))]
            target_edges = set(target)
            path_net = net
            for _ in range(5):
                path_arcs = list(path_net)
                path_set = set(path_net)
                overlap = len(path_set & target_edges)
                advancing = []
                for p in range(len(path_arcs)):
                    for q in range(p + 1, len(path_arcs)):
                        cand = switch(path_net, p, q)
                        if cand is None:
                            continue
                        gain = len(set(cand) & target_edges) - overlap
                        if gain > 0:
                            advancing.append((gain, cand))
                if not advancing:
                    break
                best_gain = max(gain for gain, _ in advancing)
                choices = [cand for gain, cand in advancing if gain == best_gain]
                # Offer a few alternative path steps, then continue along one.
                moves.update(choices[:3])
                path_net = choices[int(rng.integers(len(choices)))]
