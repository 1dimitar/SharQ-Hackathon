<DESCRIPTION>
Reserve one LP evaluation in each batch for a move that is structurally novel relative to several leading archive members. The current batch selection fills all available slots with quality-ranked moves, so its tail-exploration step usually has no effect. This change keeps up to `batch_size - 1` quality-selected moves, then uses the remaining slot for the shortlist candidate with the greatest summed distance from the leading archive members; surrogate rank breaks ties. This adds archive-wide exploration without replacing the batch’s main quality bias.
