<DESCRIPTION>
Track how often each archived network is selected and how often its neighborhood produces a better-scoring network. Select parents with a weighted exploration rule that still favors high-ranked solutions, but gives underexplored and productive parents more opportunities than repeatedly selected, unproductive ones. This targets search effort at promising regions while retaining coverage of the archive.

    def select_parent(pop):
        # Rank preserves exploitation; visit and win counts balance exposure
        # against neighborhoods that have recently yielded improvements.
        if not pop:
            return best_net
        weights = []
        for rank, net in enumerate(pop):
            visits = parent_visits.get(net, 0)
            wins = parent_wins.get(net, 0)
            rank_bonus = 0.5 * math.exp(-rank / 6.0)
            exploration = 1.0 / math.sqrt(1.0 + visits)
