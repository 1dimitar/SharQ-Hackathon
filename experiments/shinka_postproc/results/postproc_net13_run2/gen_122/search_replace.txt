<DESCRIPTION>
Parent selection currently adjusts an elite/uniform mixture only by visit counts, stalls, and successes. Since the archive already contains structurally diverse networks, explicitly weighting members by their distance from the elite group gives underexplored regions a better chance of producing proposals, while retaining the existing quality and productivity biases. The novelty multiplier is bounded, so it encourages exploration without allowing distant, weak archive members to dominate selection.

    def select_parent(pop):
        """Balance quality and productivity with explicit structural exploration."""
        if not pop:
            return best_net

        elite_n = min(6, len(pop))
        baseline = [
            (0.48 / elite_n if i < elite_n else 0.0)
            + 0.52 / len(pop)
            for i in range(len(pop))
        ]
        elite = pop[:elite_n]
        weights = []
        for net, base in zip(pop, baseline):
            visits = parent_visits.get(net, 0)
            stalls = parent_stalls.get(net, 0)
            successes = parent_successes.get(net, 0)
            productivity = (
                (1.0 + 0.7 * successes)
                / (1.0 + 0.35 * visits + 0.65 * stalls)
            )

            # Prefer archive members outside the elite's structural neighborhood.
            novelty = min(distance(net, other) for other in elite)
            novelty_factor = 0.75 + 0.5 * min(1.0, novelty / 12.0)
            weights.append(base * productivity * novelty_factor)

        total = sum(weights)
        if total <= 0:
            return pop[int(rng.integers(len(pop)))]
        return pop[int(rng.choice(len(pop), p=[w / total for w in weights]))]
