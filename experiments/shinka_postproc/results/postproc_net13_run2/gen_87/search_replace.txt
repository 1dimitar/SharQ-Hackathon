<DESCRIPTION>
Adapt which move structures receive LP calls using their confirmed improvement rates. Classify proposals by the number of changed links (two-switch, three-link rotation, or larger move), then maintain a smoothed success estimate for each class. Batch selection gives stronger representation to move classes that have actually improved their parent, while retaining a floor for every class so under-sampled operators continue to be explored. This makes the expensive LP budget respond to observed network-quality improvements rather than relying on a fixed mix of proposals.
</DESCRIPTION>

    def select_batch(moves, parent, limit=3):
        if not moves:
            return []
        base = energy(parent)
        ranked = sorted(moves, key=lambda x: energy(x) - base)
        # Group by move size: 4 changed arcs are a two-switch, 6 a rotation,
        # and larger differences are relinking or multi-switch perturbations.
        groups = {2: [], 3: [], 4: []}
        parent_set = set(parent)
        for net in ranked:
            changed = len(parent_set ^ set(net)) // 2
            kind = 2 if changed <= 2 else (3 if changed == 3 else 4)
            groups[kind].append(net)

        selected = []
        # Try one proposal from each move class, in order of its smoothed
        # LP-confirmed improvement rate; the exploration floor is implicit.
        kinds = [k for k in groups if groups[k]]
        kinds.sort(
            key=lambda k: operator_stats[k][0] / operator_stats[k][1],
            reverse=True,
        )
        for kind in kinds:
            if len(selected) >= limit:
                break
            for net in groups[kind]:
                if all(dist(net, old) >= 2 for old in selected):
                    selected.append(net)
                    break

        # Use remaining capacity on the best surrogate-ranked proposals.
        for net in ranked:
            if len(selected) >= limit:
                break
            if net not in selected:
                selected.append(net)
        return selected[:limit]
