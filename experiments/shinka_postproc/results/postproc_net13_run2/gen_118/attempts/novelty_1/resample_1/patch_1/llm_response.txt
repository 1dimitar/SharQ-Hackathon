<DESCRIPTION>
Parent selection already rewards infrequent and stalled members, but its non-elite sampling does not account for structural distance from the strongest networks. Add a bounded novelty bonus based on distance from the top six, while retaining rank, visit, and stall factors. Slightly reduce the probability of choosing directly from the elite set so that distant archive members receive more opportunities to explore distinct network regions.

    def choose_parent(pop):
        """Balance elite exploitation with structural and visit-based exploration."""
        if len(pop) == 1:
            return pop[0]

        elite_count = min(6, len(pop))
        elite_probability = max(
            0.20, 0.50 - 0.05 * (nonimproving_rounds // 8)
        )
        if rng.random() < elite_probability:
            return pop[int(rng.integers(elite_count))]

        elite = pop[:elite_count]
        weights = []
        for rank, net in enumerate(pop):
            quality = 1.0 / (1.0 + 0.08 * rank)
            underexplored = 1.0 / ((1.0 + visits.get(net, 0)) ** 0.8)
            stale_bonus = 1.0 + min(3.0, stalls.get(net, 0) * 0.15)
            structural_novelty = min(
                distance(net, leader) for leader in elite
            ) / max(1, 2 * len(net))
            diversity_bonus = 1.0 + 1.25 * structural_novelty
            weights.append(
                quality * underexplored * stale_bonus * diversity_bonus
            )

        for net, weight in zip(pop, weights):
            pick -= weight
            if pick <= 0:
                return net
        return pop[-1]
