<DESCRIPTION>
Add a short, guided path-relinking phase before screening each parent’s neighborhood. It chooses a strong, topologically distant archive member as a guide, then greedily applies degree-preserving two-switches that reduce the symmetric difference from that guide. Intermediate networks are added to the existing move set, so the established surrogate screening still decides which ones merit LP calls. This explores directed routes between good regions rather than relying only on random kicks, while keeping the added work bounded and requiring no extra LP calls by itself.
</DESCRIPTION>
