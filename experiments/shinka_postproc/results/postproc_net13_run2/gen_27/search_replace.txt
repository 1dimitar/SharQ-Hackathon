<DESCRIPTION>
The current batch screen ranks proposals almost entirely by QUBO energy, even though the LP detail identifies links that can directly limit the objective. Reserve part of each LP batch for low-energy proposals that modify positive-price bottleneck links, then fill the rest using the existing energy ranking. This adds targeted congestion-oriented exploration without letting the LP’s dual information crowd out surrogate-favored moves. The detail lookup is cached for an already-scored parent, so it does not spend an LP call.
