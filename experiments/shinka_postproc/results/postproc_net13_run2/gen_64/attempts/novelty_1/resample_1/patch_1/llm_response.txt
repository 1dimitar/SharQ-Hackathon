<DESCRIPTION>
Use recurring edges from the best, structurally diverse LP-scored archive members as a limited proposal signal. Generate two-switches that introduce one of these consensus edges, then reserve at most one batch slot for the best such move on a minority of search rounds. This gives the search a way to combine promising features across archive regions without letting one archive member’s edges dominate the ordinary bottleneck-, energy-, and exploration-guided search.

        """Find recurring edges among good archive members from distinct regions."""
        ranked = sorted(seen, key=seen.get)
        reps = []
        for net in ranked:
            if all(distance(net, old) >= 4 for old in reps):
                reps.append(net)
            if len(reps) >= 12:
                break
        counts = {}
        for net in reps:
            for edge in edges(net):
                counts[edge] = counts.get(edge, 0) + 1
        threshold = max(2, (len(reps) + 3) // 4)
        return {edge for edge, count in counts.items() if count >= threshold}
