<DESCRIPTION>
Replace the fixed elite-versus-uniform parent choice with adaptive selection based on archive novelty, observed improvement, and under-exploration. Each parent’s attempts and cumulative relative score gains are tracked; parents that have produced useful improvements receive a modest productivity bonus, while rarely selected and structurally distinct archive members retain a chance to be explored. Update these statistics after each evaluated neighborhood. This makes parent selection responsive to actual LP results rather than relying only on rank or random selection.
</DESCRIPTION>

    def select_parent(pop):
        """Balance score rank, structural novelty, productivity, and exploration."""
        if not pop:
            return best_net
        total_uses = sum(parent_uses.values())
        weights = []
        for rank, net in enumerate(pop):
            uses = parent_uses.get(net, 0)
            nearest = min(
                (distance(net, other) for other in pop if other != net),
                default=26,
            )
            novelty = min(1.0, nearest / 26.0)
            quality = 1.0 / (1.0 + 0.04 * rank)
            productivity = parent_gain.get(net, 0.0) / max(1, uses)
            productivity_factor = 0.75 + min(1.5, 500.0 * productivity)
            exploration = 0.35 * math.sqrt(
                math.log(total_uses + 2.0) / (uses + 1.0)
            )
            weights.append(
                quality * (0.55 + novelty) * productivity_factor
                * (1.0 + exploration)
            )

            pick -= weight

        return pop[-1]
