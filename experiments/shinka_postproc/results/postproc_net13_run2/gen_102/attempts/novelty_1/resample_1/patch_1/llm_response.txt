<DESCRIPTION>
The current operator adaptation only chooses at most one move from each operator per batch; any remaining LP slots go to the globally best energy-ranked moves. With the default batch size of three, this gives the operator success statistics little influence over LP-call allocation. Increase the default batch modestly and use the smoothed operator rates to choose each batch slot, while retaining surrogate-ranked candidate ordering within each operator. This lets operators that have recently produced improvements receive more evaluations, but the additive floor and Beta smoothing preserve exploration. The existing fallback still ensures a full batch when operator-specific candidates run out.
</DESCRIPTION>
