<DESCRIPTION>
The current batch screen uses a symmetric-difference threshold of 2, which often does little to distinguish valid two-switch moves. Build the first part of each LP batch from a small, energy-ranked shortlist using farthest-point selection instead: keep the best-energy move as an anchor, then prefer moves that are topologically distant from those already selected. Require distance 6 where possible, relax to 4 if needed, and retain the existing energy-ranked fill as a fallback. This aims to spend LP calls across more distinct network variants without losing the surrogate’s guidance.
</DESCRIPTION>
