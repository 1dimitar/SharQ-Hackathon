<DESCRIPTION>
The existing rotation sampler draws triples uniformly, then discards triples that do not include a bottleneck link. When only a few links are hot, that wastes many trials. Keep the random rotation component for exploration, but add a size-scaled set of rotations that deliberately include the highest-pressure links. Each rotation preserves all in- and out-degrees, and the existing batch screen still decides which proposals merit LP calls. This makes dual guidance more productive without letting it monopolize the search.
</DESCRIPTION>
