<DESCRIPTION>
Add a short path-relinking search from each selected parent toward the best network found so far. Each step uses a valid degree-preserving two-switch that increases the number of links shared with the incumbent, and contributes the intermediate networks to the existing move pool. This can explore useful combinations of two good topologies that ordinary local moves may not prioritize.

Also fix the batch filler: its current surrogate-ranking loop fills every available slot before the tail-exploration code runs, so the intended random exploration slot is never reserved. Leave one slot for a random fresh move when alternatives remain, preserving a small amount of exploration alongside the ranked trials. Both changes scale with n and use the existing RNG and LP-scoring pipeline.
