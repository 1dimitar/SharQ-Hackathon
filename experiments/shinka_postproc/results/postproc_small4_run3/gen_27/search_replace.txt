<DESCRIPTION>
Augment the existing ridge predictor with inexpensive uncertainty estimates from its regularized inverse Gram matrix. Reserve one LP trial for a competitive proposal with a favorable lower confidence bound, rather than allocating every remaining trial to predicted mean quality.

Keep the existing learned-quality, energy, routing, novelty, and random allocations. Increase batch capacity only when necessary to accommodate the uncertainty trial without crowding those allocations out. Cap uncertainty at the observed residual scale and restrict acquisition to the better-predicted half of the shortlist, reducing the risk of chasing poorly supported outliers. This adds no routing computations or LP calls beyond the fixed total budget.
</DESCRIPTION>

    def predictions(X):
        """Return calibrated means and bounded epistemic uncertainties."""
        if len(training_y) < max(3 * n, 36):
            return None, None
        A = np.asarray(training_x)
        y = np.asarray(training_y)
        mean = A.mean(axis=0)
        sd = np.maximum(A.std(axis=0), 1e-8)
        Z = np.clip((A - mean) / sd, -12.0, 12.0)
        target_mean = float(y.mean())
        identity = np.eye(A.shape[1])
        gram = Z.T @ Z + 8.0 * identity
        try:
            # One small solve supplies both the original ridge coefficients
            # and the covariance geometry needed for uncertainty estimates.
            solution = np.linalg.solve(
                gram,
                np.column_stack((Z.T @ (y - target_mean), identity)),
            )
        except np.linalg.LinAlgError:
            return None, None
        coef = solution[:, 0]
        inverse = solution[:, 1:]
        W = np.clip((X - mean) / sd, -12.0, 12.0)
        predicted = target_mean + W @ coef
        residual = y - target_mean - Z @ coef
        variance = float(residual @ residual) / max(
            1, len(y) - A.shape[1] - 1
        )
        leverage = np.einsum("ij,jk,ik->i", W, inverse, W)
        # Include uncertainty in the intercept, but do not let extrapolation
        # claim more than one residual standard deviation of optimism.
        leverage = np.clip(leverage + 1.0 / len(y), 0.0, 1.0)
        uncertainty = np.sqrt(max(0.0, variance) * leverage)
        return predicted, uncertainty
