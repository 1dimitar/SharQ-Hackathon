stall_escalated_rotations
</NAME>

<DESCRIPTION>
The current search samples the same fixed number of targeted rotations for every parent, even when a parent has repeatedly failed to produce an improvement. Track consecutive unproductive batches per parent and escalate the number of rotation triples only for stalled parents. Reserve some batch slots for the best-ranked rotation proposals at high stall levels, so escalation actually spends LP calls on those moves rather than letting them be crowded out by switches. Reset the stall count when the parent’s batch finds a new incumbent. This directs more exploratory effort toward difficult basins while preserving the usual switch-heavy search elsewhere.
</DESCRIPTION>
