<DESCRIPTION>
Retain the direct-demand reward, but add discounted two-hop rewards only when an intermediate node is a plausible relay: its total incoming and outgoing demand should both be substantial. This targets useful path structure without treating every possible intermediate as equally valuable. Normalize each origin-destination pair’s relay rewards so that adding many candidate intermediates does not multiply its influence. The resulting interactions are sparse enough to stay below the quadratic-term limit, and the stronger degree penalty helps keep the cost terms from overwhelming the evaluator’s degree constraints.
</DESCRIPTION>

    d = np.asarray(demand, dtype=float)
    n = len(d)
    scale = float(d.max()) or 1.0
    ds = d / scale

    # Keep the baseline incentive for links carrying substantial direct traffic.
    linear = {
        (i, j): -float(ds[i, j])
        for i in range(n) for j in range(n) if i != j
    }

    # A node is a more credible relay when it has both traffic arriving and
    # traffic leaving. This downweights two-hop paths through one-sided nodes.
    row = ds.sum(axis=1)
    col = ds.sum(axis=0)
    relay = np.sqrt(np.maximum(row, 0.0) * np.maximum(col, 0.0))
    rmax = float(relay.max()) or 1.0
    relay = relay / rmax

    quadratic = {}
    for i in range(n):
        for k in range(n):
            if i == k or ds[i, k] <= 0:
                continue
            candidates = []
            for j in range(n):
                if j != i and j != k and relay[j] > 0:
                    # Prefer relays connected to both sides of this OD pair.
                    suitability = relay[j] * (
                        0.25 + 0.75 * min(1.0, ds[i, j] + ds[j, k])
                    )
                    if suitability > 0:
                        candidates.append((j, suitability))
            total = sum(v for _, v in candidates)
            if total <= 0:
                continue
            for j, suitability in candidates:
                a, b = (i, j), (j, k)
                key = (a, b) if a < b else (b, a)
                # Discount indirect service and distribute the OD reward over
                # candidate relays, preventing high-degree interaction bias.
                quadratic[key] = quadratic.get(key, 0.0) - (
                    0.30 * float(ds[i, k]) * suitability / total
                )

    penalty_weight = 3.0
    return linear, quadratic, penalty_weight
