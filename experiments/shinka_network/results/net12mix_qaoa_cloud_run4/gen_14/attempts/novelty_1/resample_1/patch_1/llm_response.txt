<DESCRIPTION>
The current linear term gives direct-demand links a reward proportional to demand, so a few very large OD pairs can dominate many useful moderate-demand links. Replace that reward with a square-root normalized reward, while keeping the existing two-hop couplings unchanged. This preserves the preference for direct service but compresses the range of direct rewards, giving the routing structure represented by the quadratic terms more influence. It also changes only the linear-term construction, so it does not increase the interaction count or computational cost.
</DESCRIPTION>
