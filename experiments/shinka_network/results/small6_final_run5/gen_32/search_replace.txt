<DESCRIPTION>
Replace the broad penalty on every pair of links sharing a node with a sparse penalty on only the most redundant branch pairs. Two branches are redundant when their demand-weighted traffic profiles are similar, so selecting both is less likely to provide useful routing alternatives. This makes the congestion proxy more specific to the demand matrix, reduces unnecessary couplings, and may improve both QUBO sampling and energy-based ranking of link exchanges. The replacement adds at most three pairs per node in each direction.
</DESCRIPTION>

    # overlap substantially. Broad same-node penalties also discourage
    # useful, complementary branches.
    for inbound in (False, True):
        od = t.T if inbound else t
        profiles = np.sqrt(od).copy()
        np.fill_diagonal(profiles, 1.0)

        for center in range(n):
            weights = od[center]
            if float(weights.sum()) <= 0.0:
                continue

            gram = (profiles * weights[None, :]) @ profiles.T
            branches = [j for j in range(n) if j != center]
            normalizer = max(float(gram[j, j]) for j in branches)
            if normalizer <= 1e-12:
                continue

            redundant = []
            for position, j in enumerate(branches):
                for k in branches[position + 1:]:
                    overlap = float(gram[j, k]) / normalizer
