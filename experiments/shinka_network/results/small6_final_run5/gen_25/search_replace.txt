<DESCRIPTION>
Count how often each link is used in a selected two-hop route, then mildly attenuate quadratic terms involving heavily reused links. This regularizes variables that otherwise accumulate disproportionate interaction strength, which can distort both sampling and energy-based ranking. The interface provides only a scalar degree penalty, so this targets interaction imbalance without adding an unsupported link-specific constraint penalty; linear demand rewards and the existing degree penalty remain unchanged.
</DESCRIPTION>
