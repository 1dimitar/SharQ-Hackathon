<DESCRIPTION>
Add demand-aware neighbor-diversity couplings. Two outgoing neighbors are redundant when they both serve the same destinations needed by their source; two incoming neighbors are redundant when they both collect traffic from the same origins needed by their destination. Penalizing this overlap encourages complementary neighbors rather than merely accumulating attractive two-hop paths.

Center each node’s overlap scores before sparsification: the common component is constant on valid degree-two topologies and carries no ranking information. Retain only the n//2 strongest deviations per node and direction, adding at most n² couplings. A modest coefficient preserves the existing direct, route, cut, and penalty terms. This targets typical-sample quality and exchange rankings without substantially enlarging the coupling graph.
</DESCRIPTION>

    for center in range(n):

        for incoming_direction in (False, True):
            if incoming_direction:
                demand_profile = z[:, center]
                service = incoming_service
            else:
                demand_profile = z[center, :]
                service = outgoing_service

            total = float(demand_profile.sum())
            if total <= 0.0:
                continue

            # A weighted Gram matrix measures shared useful service.
            overlap = (
                (service * demand_profile[None, :]) @ service.T
            ) / total
            candidates = [
                (float(overlap[j, k]), j, k)
                for position, j in enumerate(neighbors)
                for k in neighbors[position + 1:]
            ]
            if not candidates:
                continue

            # Every valid topology selects exactly one neighbor pair per
            # direction, so this common offset has no ranking information.
            common = sum(value for value, _, _ in candidates) / len(candidates)
