<DESCRIPTION>
Make transit-node pressure matter slightly more when routing demands between heavily loaded endpoints. The bounded exponent changes which candidate transit nodes rank highest without changing the default two-route selection or the conditional third-route rule. This keeps the route set sparse while making selected indirect paths more sensitive to likely endpoint congestion, which should help both annealing and the post-processor’s move ranking.
</DESCRIPTION>
