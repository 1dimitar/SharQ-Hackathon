<DESCRIPTION>
Add sparse outgoing and incoming neighbor-service factors. For each node, estimate how well each possible neighbor can serve destinations (or origins) using a balanced demand-affinity profile. Score each neighbor pair for coverage and load balance, then decompose that score into link-level linear preferences and a sparse residual interaction. This targets the competition between the two links available at each node, rather than simply rewarding more two-hop paths. The pair budget is set independently of factor strength, at about n/3 per node and direction, keeping the added coupling count modest while also providing energy differences useful for ranking valid topologies and exchanges.
</DESCRIPTION>

            traffic_view = z.T if reverse else z
            totals = traffic_view.sum(axis=1)
            mean_total = float(totals.mean())

            if mean_total <= 1e-15:
                continue

            for node in range(n):
                total = float(totals[node])
                if total <= 1e-15:
                    continue

                neighbors = [a for a in range(n) if a != node]
                m = len(neighbors)
                left, right = np.triu_indices(m, 1)
                weights = traffic_view[node] / total
                neighbor_service = service[neighbors, :]
                first_service = neighbor_service[left]
                second_service = neighbor_service[right]
                combined = np.maximum(
                    first_service + second_service, 1e-12
                )

                coverage_cost = -np.log(combined) @ weights
                load_difference = np.abs(
                    ((first_service - second_service) / combined) @ weights
                )
                costs = coverage_cost + 0.55 * load_difference
                grand_mean = float(costs.mean())
                spread = float(np.sqrt(np.mean((costs - grand_mean) ** 2)))
                if spread <= 1e-12:
                    continue

                dense_cost = np.zeros((m, m), dtype=float)
                dense_cost[left, right] = costs
                dense_cost[right, left] = costs
                row_mean = dense_cost.sum(axis=1) / (m - 1)
                main_effect = (

                residual = (
