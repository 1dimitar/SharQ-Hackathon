<DESCRIPTION>
Refine the existing two-node-cut correction to measure endpoint vulnerability separately for outgoing and incoming traffic. The current factor combines both directions into one incident-demand ratio, which can blur a strongly one-way load. For each endpoint, the replacement compares external outgoing and incoming demand with the corresponding directional totals, then uses the larger share. Taking the more vulnerable endpoint’s value makes the cut correction more sensitive to asymmetric traffic that can stress a directional capacity.
</DESCRIPTION>
