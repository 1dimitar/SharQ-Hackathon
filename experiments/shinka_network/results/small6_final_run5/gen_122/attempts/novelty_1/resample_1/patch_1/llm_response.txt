<DESCRIPTION>
Add a compact service-coverage and load-balance estimate for pairs of outgoing and incoming links at each node. Because every valid topology selects exactly two links in each direction, the pair cost can distinguish link pairs that jointly serve traffic broadly and evenly from pairs that leave similar traffic competing for the same service. Decompose each pair cost into linear endpoint effects and a zero-row-mean residual, then retain only the most informative residual couplings. The capped pair budget keeps the added model sparse, while a moderate strength limits interference with the existing direct-link and route terms.
</DESCRIPTION>

    )
    base_strength = 0.18 * mean_direct * depth_scale
