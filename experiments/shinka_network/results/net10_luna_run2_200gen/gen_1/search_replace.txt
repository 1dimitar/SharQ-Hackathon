<DESCRIPTION>
Add a modest reward for selected two-hop paths, but discount it when the intermediate node has high total traffic or either path link already serves substantial direct demand. This uses the limited in/out degree as a rough indicator of transit congestion, so it is more selective than a uniform two-hop reward. The number of quadratic terms is at most n(n−1)(n−2), within the stated limit. The existing direct-demand reward and degree penalty are retained.
</DESCRIPTION>

    n = len(demand)
    scale = float(np.max(demand)) or 1.0
    linear = {
        (i, j): -float(demand[i, j]) / scale
        for i in range(n) for j in range(n) if i != j
    }

    # A busy transit node has only two outgoing links over which to spread
    # through-traffic, so discount paths through nodes with large incident demand.
    incident = np.sum(demand, axis=0) + np.sum(demand, axis=1)
    mean_incident = float(np.mean(incident)) or 1.0
    node_pressure = np.maximum(0.75, incident / mean_incident)

    # Reward useful two-hop alternatives, while discounting paths whose links
    # are already likely to be loaded by their own direct traffic.
    quadratic = {}
    path_strength = 0.16
    for i in range(n):
        for j in range(n):
            if j == i:
                continue
            for k in range(n):
                if k == i or k == j:
                    continue
                through_demand = float(demand[i, k])
                if through_demand <= 0.0:
                    continue
                edge_pressure = (
                    float(demand[i, j]) + float(demand[j, k])
                ) / scale
                weight = (
                    -path_strength * (through_demand / scale)
                    / (node_pressure[j] * (1.0 + 0.5 * edge_pressure))
                )
                quadratic[((i, j), (j, k))] = weight

    penalty_weight = 1.0
    return linear, quadratic, penalty_weight
