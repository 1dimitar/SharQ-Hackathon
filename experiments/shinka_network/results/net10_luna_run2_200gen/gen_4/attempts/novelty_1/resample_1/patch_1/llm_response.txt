<DESCRIPTION>
Add a deliberately weak reward for two-hop routes, alongside the existing direct-demand reward. A selected path i → j → k can help serve demand[i, k] when a direct link is unavailable; scaling this contribution to 0.12 avoids letting the abundance of possible two-hop paths overwhelm the direct-link signal. The node-throughput factor discounts paths through nodes with high total incident demand, which are more likely to be congested transit points. Degree constraints remain the evaluator’s responsibility.
</DESCRIPTION>

    n = len(demand)
    scale = float(demand.max()) or 1.0
    linear = {
        (i, j): -float(demand[i, j]) / scale
        for i in range(n) for j in range(n) if i != j
    }

    # A weak two-hop reward encourages links that jointly provide a short
    # route for traffic not captured by either link's own direct demand.
    row_load = np.asarray(demand, dtype=float).sum(axis=1)
    col_load = np.asarray(demand, dtype=float).sum(axis=0)
    node_load = row_load + col_load
    typical_load = float(node_load.mean()) or 1.0
    quadratic = {}
    for i in range(n):
        for j in range(n):
            if i == j:
                continue
            for k in range(n):
                if k == i or k == j:
                    continue
                traffic = float(demand[i, k])
                if traffic <= 0.0:
                    continue
                # Discount busy transit nodes to avoid overloading their
                # limited incoming and outgoing capacity.
                congestion = 1.0 + float(node_load[j]) / typical_load
                weight = -0.12 * (traffic / scale) / congestion
                quadratic[((i, j), (j, k))] = weight

    penalty_weight = 1.0
    return linear, quadratic, penalty_weight
