<DESCRIPTION>
Limit the aggregate two-hop reward for each origin-destination pair to 75% of that pair’s direct-link reward. The current code assigns a reward to every feasible intermediate node, so many individually modest two-hop terms can collectively dominate the direct-service signal. Capping their total magnitude preserves the relative ranking of candidate paths while reducing the chance that the QUBO over-favors networks with many indirect routes. This follows the supplied recommendation and keeps the number of quadratic terms unchanged.
</DESCRIPTION>

    # Without a cap, the many possible intermediates can collectively swamp
    # the direct-link signal even when each individual path looks attractive.
    for i in range(n):
        for k in range(n):
            if i == k or d[i, k] <= 0.0:

            path_terms = []

            for j in range(n):
