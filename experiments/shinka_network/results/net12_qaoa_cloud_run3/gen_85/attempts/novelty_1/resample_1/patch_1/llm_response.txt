Rank relays using the suggested balanced-leg affinity, `min(a, b) + 0.25 * max(a, b)`, discounted by node pressure. This favors paths whose two legs both have useful demand, while still allowing some preference for a strong individual leg. Preserve the existing path-support and pressure-discounted coupling weight for selected relays.
