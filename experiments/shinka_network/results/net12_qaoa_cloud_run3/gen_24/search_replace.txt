<DESCRIPTION>
Score each candidate relay using both adjacent demand legs, rather than choosing relays solely by node pressure. The minimum-leg-sensitive geometric score suppresses relays with one strong leg but one weak leg, while retaining the existing pressure discount and distributing each OD pair’s bounded reward over all candidate relays. This changes only the relay ranking signal; it adds no quadratic terms.
