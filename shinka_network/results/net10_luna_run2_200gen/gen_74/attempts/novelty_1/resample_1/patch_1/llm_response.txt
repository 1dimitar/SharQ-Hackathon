<DESCRIPTION>
Cap the aggregate two-hop reward for each origin–destination pair at `indirect_fraction * demand[i, k] / scale`. The current per-intermediate reward is divided by four, reflecting the maximum number of such paths in a valid degree-two topology, but summing over all candidate intermediates can exceed that budget. Rescale an OD pair’s existing candidate rewards only when their sum exceeds the cap. This retains the current transit preference and supported-path structure while preventing many possible intermediates from collectively overwhelming the direct-link signal; it does not add quadratic terms.
</DESCRIPTION>
