sparse_three_hop_closure

<DESCRIPTION>
Add one supported three-hop alternative for heavy OD pairs whose two-hop options are weak or nearly tied. Require the longer route to have stronger pressure-adjusted leg support than the best two-hop route.

Approximate three-hop completion using two adjacent-link couplings, weighted by demand-derived probabilities for the omitted legs. A positive bridge correction centers this approximation: selecting the bridge alone earns no reward. This is a quadratic heuristic, not an exact encoding of three-hop reachability.

Scale its strength by the fraction of destinations that cannot fit within an ideal two-hop, degree-two expansion. This emphasizes larger networks without changing the existing surrogate or constraint weight. Each eligible OD pair adds at most two couplings, often overlapping existing terms.
</DESCRIPTION>

        row_total = affinity.sum(axis=1)
        col_total = affinity.sum(axis=0)
        link_prior = np.minimum(

            2.0 * affinity / np.sqrt(np.maximum(
                row_total[:, None] * col_total[None, :], 1e-15

        pressure_product = node_pressure[:, None] * node_pressure[None, :]
        three_kernel = normalized / (pressure_product ** 1.125)
        two_discount = node_pressure ** 0.75

        for i in range(n):
            for k in range(n):
                if (
                    i == k
                    or traffic[i, k] <= 0.0
                    or traffic[i, k] < cutoff
                ):
                    continue

                two_quality = (
                    np.sqrt(normalized[i] * normalized[:, k])
                    / two_discount
                )
                two_quality.sort()
                best_two = float(two_quality[-1])
                second_two = float(two_quality[-2])
                if best_two >= 0.55 and second_two < 0.94 * best_two:
                    continue

                # Rows and columns are the two intermediate nodes.
                # A zero-demand leg makes the complete route's score zero.
                quality = np.cbrt(
                    normalized[i, :, None]
                    * three_kernel
                    * normalized[:, k][None, :]
                )
                quality[[i, k], :] = 0.0
                quality[:, [i, k]] = 0.0
                a, b = divmod(int(np.argmax(quality)), n)
                if float(quality[a, b]) < max(0.50, 1.08 * best_two):
                    continue

                support = float(
                    0.70 * normalized[i, k] + 0.30 * roots[i, k]
                )
                leg_sum = float(
                    normalized[i, a]
                    + normalized[a, b]
                    + normalized[b, k]
                )
                weight = (
                    0.24 * long_hop_share * support
                    / (float(pressure_product[a, b]) * (1.0 + 0.5 * leg_sum))
                )

                first, bridge, last = (i, a), (a, b), (b, k)
                p_first = float(link_prior[i, a])
                p_last = float(link_prior[b, k])

                # For route bits x,y,z, use
                # -w*y*(p_last*x + p_first*z - p_first*p_last).
                # This matches completion's value and first derivatives
                # at the endpoint priors without coupling disconnected stubs.
                linear[bridge] += float(weight * p_first * p_last)

                    (bridge, last, p_first),

                    key = (
                        (left, right) if left < right else (right, left)
                    )
                    quadratic[key] = float(
                        quadratic.get(key, 0.0) - weight * missing_prior
                    )

    penalty_weight = min(1.45, 1.30 + 0.008 * max(0, n - 10))
