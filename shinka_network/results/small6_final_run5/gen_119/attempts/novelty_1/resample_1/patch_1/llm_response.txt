normalized_cut_reallocation
</NAME>

<DESCRIPTION>
Strengthen the two-node cut correction slightly while reallocating it toward more vulnerable endpoint pairs. The vulnerability multiplier is widened to 0.8–1.2, then normalized by the squared-load-weighted mean across cuts. This preserves the total load-weighted cut correction, so the change tests where that signal is allocated rather than accidentally changing its overall scale. The calculation remains quadratic in the number of nodes and does not add couplings beyond the existing reciprocal-link terms.
</DESCRIPTION>

            internal = float(traffic[i, j] + traffic[j, i])
            external = max(
                0.0,
                max(
                    float(row_sum[i] + row_sum[j]),
                    float(col_sum[i] + col_sum[j]),
                ) - internal,
            )
            if external <= 0.0:

            endpoint_ratio = 0.5 * (
                external / max(float(incident[i]), 1e-12)

            )
            vulnerability = float(np.clip(
                0.85 + 0.30 * endpoint_ratio, 0.80, 1.20

            squared_load = (external / incident_scale) ** 2

    # it toward pairs whose endpoints are more exposed to external traffic.
    if cut_records:
