<DESCRIPTION>
Keep the baseline’s direct-demand reward, but add modest, demand-scaled pair rewards for two-hop paths and mutually useful reciprocal links. The two-hop reward is discounted across the available intermediates, avoiding the large aggregate incentive of rewarding every path equally. Reciprocal synergy is stronger when demand runs in both directions. Finally, raise the degree-penalty weight so degree violations are less attractive relative to the normalized cost terms. The number of quadratic terms remains below the stated limit.

    n = len(demand)
    scale = float(np.max(demand)) or 1.0
    linear = {
        (i, j): -float(demand[i, j]) / scale
        for i in range(n) for j in range(n) if i != j
    }

    quadratic = {}

    # A short path can share an OD flow across two links. Discount each
    # candidate intermediary so the total incentive does not grow linearly
    # with the number of possible paths.
    path_discount = 0.18 / max(1.0, (n - 2) ** 0.5)
    for i in range(n):
        for j in range(n):
            if j == i:
                continue
            for k in range(n):
                if k == i or k == j:
                    continue
                value = float(demand[i, k])
                if value > 0.0:
                    quadratic[((i, j), (j, k))] = -path_discount * value / scale

    # Reciprocal links are especially useful when traffic is substantial in
    # both directions, so give such pairs a small additional joint reward.
    for i in range(n):
        for j in range(i + 1, n):
            mutual = min(float(demand[i, j]), float(demand[j, i]))
            if mutual > 0.0:
                quadratic[((i, j), (j, i))] = -0.10 * mutual / scale

    penalty_weight = 4.0
    return linear, quadratic, penalty_weight
