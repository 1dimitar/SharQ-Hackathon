<DESCRIPTION>
Keep the direct-demand reward, but add a deliberately modest reward for useful two-hop routes. Unlike an unweighted two-hop term, this discounts routes through intermediates with high total in- and out-traffic, which are more likely to become transit bottlenecks. The terms connect links that form actual directed paths and stay below the quadratic-term limit. Raising the degree-penalty weight should also make the QUBO less willing to trade degree violations for small changes in the surrogate cost.
</DESCRIPTION>

    n = len(demand)
    scale = float(demand.max()) or 1.0
    linear = {
        (i, j): -float(demand[i, j]) / scale
        for i in range(n) for j in range(n) if i != j
    }

    # Encourage useful two-hop alternatives, but discount intermediates with
    # high traffic intensity so the surrogate does not over-favor transit hubs.
    node_load = demand.sum(axis=0) + demand.sum(axis=1)
    mean_load = float(node_load.mean()) or 1.0
    congestion = 1.0 + node_load / mean_load
    quadratic = {}
    path_strength = 0.18
    for i in range(n):
        for j in range(n):
            if j == i:
                continue
            first = (i, j)
            for k in range(n):
                if k == i or k == j:
                    continue
                traffic = float(demand[i, k])
                if traffic <= 0.0:
                    continue
                second = (j, k)
                # The two link variables jointly provide a route i -> j -> k.
                key = (first, second)
                quadratic[key] = (
                    -path_strength * (traffic / scale) / float(congestion[j])
                )

    penalty_weight = 3.0
    return linear, quadratic, penalty_weight
