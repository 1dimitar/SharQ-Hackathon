<DESCRIPTION>
Preserve separate representatives of LP quality, QUBO energy, and routing-proxy quality in the archive, then deliberately sample parents from those groups. The current archive is ranked only by LP score, so good networks favored by a different signal can disappear before they have had a chance to improve. Routing proxy values are recorded only for networks already screened, avoiding extra routing calculations; all group sizes and archive limits scale with n.

    def archive():
        """Reserve archive places for LP, energy, and routing-proxy leaders."""
        ranked = sorted(
            (net for net in seen if math.isfinite(seen[net])),
            key=seen.get,
        )
        out = []

        def add_group(group, limit):
            added = 0
            for net in group:
                if net in out:
                    continue
                if all(distance(net, old) >= 4 for old in out):
                    out.append(net)
                    added += 1
                    if added >= limit:
                        break

        elite_count = max(4, n // 2)
        add_group(ranked, elite_count)
        energy_ranked = sorted(ranked, key=energy)
        add_group(energy_ranked, max(2, n // 3))
        proxy_ranked = sorted(
            (net for net in ranked if net in proxy_features),
            key=lambda net: proxy_features[net][0] + 0.25 * proxy_features[net][1],

        add_group(proxy_ranked, max(2, n // 3))

        # Fill remaining capacity with LP-ranked alternatives, without requiring
