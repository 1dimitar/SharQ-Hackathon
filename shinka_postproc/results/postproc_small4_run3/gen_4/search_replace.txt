<DESCRIPTION>
Make structural diversity effective rather than nominal. Distinct valid networks already have symmetric-difference distance at least four, so the current archive threshold of four and batch threshold of two exclude nothing. The exploration tail is also unreachable because the preceding loop fills the batch.

Keep elite exploitation, but maintain additional archive members separated by a size-dependent distance. Screen each batch using mostly low-energy moves, plus separate slots for within-batch diversity, novelty relative to previously scored networks, and unbiased exploration. Novelty is computed exactly for a small random shortlist using inexpensive integer edge masks; only evaluated networks are persistently cached. This provides exploration without making bottleneck guidance or either Hamiltonian’s surrogate dominate the search.

    def screen_batch(moves, parent, batch_size=None):
        """Mix energy exploitation, structural novelty and unbiased exploration."""
        if batch_size is None:
            batch_size = max(9, (n + 1) // 2)
        fresh = [
            m for m in moves
            if m not in seen and not tools.is_cached(m)
        ]
        if not fresh:
            return []

        ranked = sorted(fresh, key=energy)
        selected = ranked[:max(1, batch_size - 3)]
        local_masks = {}

        def mask_of(net):
            if net not in local_masks:
                local_masks[net] = topology_mask(net)
            return local_masks[net]

        def batch_distance(net):
            mask = mask_of(net)
            return min(
                ((mask ^ mask_of(old)).bit_count() for old in selected),
                default=4 * n,
            )

        # One good-energy candidate that adds the most new structure to this batch.
        local_pool = [
            net for net in ranked[:max(4 * batch_size, 2 * n)]
            if net not in selected
        ]
        if local_pool and len(selected) < batch_size:
            selected.append(max(local_pool, key=batch_distance))

        # Reserve a real novelty slot before filling the batch. Compare a small
        # random shortlist against ALL scored networks, not just the parent.
        tail = [net for net in ranked if net not in selected]
        if tail and len(selected) < batch_size:
            ids = rng.choice(len(tail), size=min(2 * n, len(tail)), replace=False)
            probes = [tail[int(i)] for i in ids]
            history = [topology_mask(net) for net in seen]

            def novelty(net):
                mask = mask_of(net)
                nearest = min(
                    ((mask ^ old).bit_count() for old in history),
                    default=4 * n,
                )
                return nearest, batch_distance(net)

            selected.append(max(probes, key=novelty))

        # Keep a final unbiased slot: neither energy nor distance is a reliable
        # enough predictor to exclude the rest of the neighborhood completely.
        tail = [net for net in ranked if net not in selected]
        while tail and len(selected) < batch_size:
            selected.append(tail.pop(int(rng.integers(len(tail)))))
        return selected
