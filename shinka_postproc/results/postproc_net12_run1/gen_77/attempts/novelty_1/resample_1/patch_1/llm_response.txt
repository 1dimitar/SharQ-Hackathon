<DESCRIPTION>
The current neighborhood screen always spends its first nine LP evaluations on the same energy-first ordering. When those moves are topologically similar, that can waste evaluations exploring nearly identical changes. Measure pairwise topology distance among the 40 best surrogate-ranked moves and adapt the initial batch: use more far-apart representatives when the pool is clustered, and retain more energy-ranked moves when it is already diverse. Keep the existing dual-guided and random reservations afterward, so this changes only the energy/diversity portion of screening.

        pool = fresh[:min(40, len(fresh))]
        if len(pool) > 1:
            pair_distances = [
                len(set(pool[i]).symmetric_difference(set(pool[j])))
                for i in range(len(pool))
                for j in range(i + 1, len(pool))
            ]
            mean_distance = sum(pair_distances) / len(pair_distances)

            mean_distance = 0.0
