<DESCRIPTION>
The current iterated search always kicks the incumbent best network, which can repeatedly revisit the same basin. Keep the incumbent as the main start, but regularly restart from a repaired network among the best 20 initial candidates. These starts preserve diversity from the QAOA pool while still favoring promising candidates. Apply a slightly larger random kick to restart starts, then use the existing descent to exploit the resulting basin. This uses the existing LP budget and search operators, without spending calls on a separate scoring phase.
</DESCRIPTION>
