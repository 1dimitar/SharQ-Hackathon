<DESCRIPTION>
The search repeatedly explores one-switch neighborhoods of a small set of strong archive members, which can leave it trapped in the same basins. Periodically create a bounded kick from a non-elite archive member using valid degree-preserving 2-switches, then include the resulting topology among proposals. This preserves the elite search while injecting a controlled, diverse starting point; the kick size grows modestly with stagnation. Track improvements in the incumbent score to reset the stagnation counter.
