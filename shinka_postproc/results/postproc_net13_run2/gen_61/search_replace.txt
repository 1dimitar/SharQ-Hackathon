<DESCRIPTION>
Track how often each archive member is selected and how much its search produces improvements. Parent selection then balances low-score elites with underexplored members and parents whose neighborhoods have recently yielded gains, instead of relying only on fixed rank-based sampling. This preserves exploitation while giving productive or neglected regions more opportunities to contribute. The counters are updated only from LP-scored results; move generation and selection remain free.

    def select_parent(pop):
        """Balance strong parents with underexplored and historically productive ones."""
        if not pop:
            return best_net
        weights = []
        for rank, net in enumerate(pop):
            visits = parent_visits.get(net, 0)
            # Rank retains a preference for good solutions; novelty and proven
            # descendant gains counterbalance repeated selection of the same elites.
            quality = 1.0 / (1.0 + rank / 5.0)
            exploration = 1.0 / math.sqrt(1.0 + visits)
            productivity = 1.0 + min(2.0, parent_gain.get(net, 0.0))
            weights.append(quality * (0.35 + 1.4 * exploration) * productivity)
        total = sum(weights)
        pick = float(rng.random()) * total
        for net, weight in zip(pop, weights):
            pick -= weight
            if pick <= 0:
                parent_visits[net] = parent_visits.get(net, 0) + 1
                return net
        net = pop[-1]
        parent_visits[net] = parent_visits.get(net, 0) + 1
        return net
