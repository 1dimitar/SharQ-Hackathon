<DESCRIPTION>
Add a cheap, independent congestion estimate to LP-batch selection. For a small energy-ranked shortlist, route each OD demand uniformly over its shortest paths and use the resulting maximum estimated link load to identify promising moves. The batch still includes energy-ranked options, so this signal supplements rather than replaces the Hamiltonian surrogate. Limiting the estimate to a shortlist keeps its cost bounded as the network size grows.

    def shortest_path_load(net):
        """Estimate congestion by splitting each OD demand across shortest paths."""
        adj = [[] for _ in range(n)]
        rev = [[] for _ in range(n)]
        for u, v in net:
            adj[u].append(v)
            rev[v].append(u)

        def bfs(graph, start):
            dist = [-1] * n
            ways = [0] * n
            dist[start] = 0
            ways[start] = 1
            queue = [start]
            for u in queue:
                for v in graph[u]:
                    if dist[v] < 0:
                        dist[v] = dist[u] + 1
                        ways[v] = ways[u]
                        queue.append(v)
                    elif dist[v] == dist[u] + 1:
                        ways[v] += ways[u]
            return dist, ways

        loads = {(u, v): 0.0 for u, v in net}
        for s in range(n):
            dist_s, ways_s = bfs(adj, s)
            for t in range(n):
                if t == s or dist_s[t] < 0:
                    continue
                dist_t, ways_t = bfs(rev, t)
                total = ways_s[t]
                if total <= 0:
                    continue
                amount = float(demand[s][t])
                for u, v in net:
                    if dist_s[u] >= 0 and dist_t[v] >= 0:
                        if dist_s[u] + 1 + dist_t[v] == dist_s[t]:
                            loads[(u, v)] += amount * ways_s[u] * ways_t[v] / total
        return max(loads.values(), default=0.0)
